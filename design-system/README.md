# テニス部 モバイルUI デザイン検証（Storybook）

## 概要
A案「ミニマルカード型」のデザイン専用プレビューです。**既存フロントエンド（`frontend/`）と独立**しており、LINE LIFF認証、バックエンド、Google Sheetsには接続しません。GitHubへのPR追加のみで、本番画面の変更・デプロイはありません。

## ローカル実行
Node.js 22以上を用意します。

```sh
cd design-system
npm install
npm run storybook
```
ブラウザで http://localhost:6006 を開きます。初回の `npm install` により `design-system/package-lock.json` が生成されます。今後CIを追加する際は、このファイルをコミットして `npm ci` で再現性を確保してください。

## 確認できるストーリー
- 未回答
- 参加予定
- 配車が必要
- 不参加
- 登録済み

Storybook Controlsでは初期ステータス・配車希望・コメントなどを変更できます。実際の画面上でも各ボタンの選択、コメント入力、デモ登録が操作できます。

### 仕様上の前提
- 回答締め切りは表示しません。
- 配車希望は「参加」を選んだ場合だけ表示します。
- 今回の「登録」はプレビュー内部状態のみ変更します。
- 練習日時や場所はデザイン確認用の架空データです。
- 画面幅375px/390px/430pxの表示を確認してください。

本番へ適用するときは、既存アプリの状態管理・バックエンド認証・出欠API仕様に沿ってコンポーネントを統合し、別PRでレビューします。
